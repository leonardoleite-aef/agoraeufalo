# Mockups Visuais: Ecossistema YouTube Lab

Aqui estão as renderizações conceituais de como a interface irá se comportar, respeitando o padrão "Calm EdTech" da plataforma.

## 1. Visão do Aluno (`youtube-lab.html`)
Esta é a tela onde o aluno consome o conteúdo. Note a divisão clara: o topo é focado 100% na experiência audiovisual imersiva (fundo escuro `Navy`), enquanto a parte inferior traz uma caixa de destaque (`amber`) para os materiais em PDF/MP3, seguida do grande botão que atua como Ponte Pedagógica para o curso oficial. A barra lateral sugere o próximo vídeo para maratonar.

## 2. Visão do Admin (`youtube-lab-manager.html`)
Este é o painel de controle. Foi desenhado para eficiência extrema. No topo, basta você colar a URL do YouTube e clicar em "Fetch Data" (Buscar) para o sistema preencher a Thumbnail e os textos. Abaixo, as caixas de upload rápido dos PDFs e MP3s, e à direita os seletores para você "cruzar" essa aula com o módulo oficial dentro do curso, gerando a ponte automaticamente.
